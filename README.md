# 🏦 Binary Classification for Bank Term Deposit

### Machine Learning Project to Predict Term Deposit Subscriptions

<br>

This project applies machine learning algorithms and data preprocessing techniques on a bank marketing dataset to predict whether a customer will subscribe to a term deposit.

<br>

### 📍 Overview

The main objective of this project is to build a robust predictive model that helps financial institutions identify potential customers, optimize marketing campaigns, and improve conversion rates using data analytics and classification algorithms.

<br>

### ✨ Key Features & Workflow

*   **Data Preprocessing:** Handling missing values, encoding categorical variables, and scaling features.
*   **Dataset Resampling:** Applying techniques like SMOTE to handle class imbalance.
*   **Machine Learning Models:** Training and evaluating various classification algorithms.
*   **Evaluation Metrics:** Using Accuracy, Precision, Recall, F1-Score, and ROC-AUC to measure model performance.

<br>

### 🛠️ Tech Stack

*   **Language:** Python
*   **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn
*   **Tools:** Jupyter Notebook / VS Code, Git & GitHub
